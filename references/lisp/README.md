# LISP baseline corpus

Original AutoLISP source for the solid-slab GAD that this project started from
([article](https://www.yogipwd.com/2023/05/explanation-of-lisp-code-for-solid-slab.html)).

Drop the `.lsp` files here verbatim — do not clean or reformat them. The
baseline is evidence of intent, so it must stay as published.

`bridgecad_refs.lisp_baseline` inventories what the source does; `docs/lisp-baseline.md`
records where the suite disagrees and what was done about it. A disagreement is
not automatically a defect — some of the LISP is pre-IRC-SP:55 — but every row
needs a disposition before the baseline is closed.
