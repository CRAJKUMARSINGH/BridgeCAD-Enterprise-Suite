------------------------------------------------------------------------
2. Root cause (proved, then fixed)
------------------------------------------------------------------------

`scripts/prove_detection.py` copies the whole working tree once per mutation
(19 copies including the control). Its IGNORE_DIRS set was incomplete, so each
copy took 7859 files / 303 MB (~45 s). With ~19 copies the harness could not
finish inside the 900 s subprocess timeout in
`tests/docs/test_detection_proof.py::_prove`, and the parent blocked in
_communicate as shown above.

Measured before the fix: 900 s subprocess timeout, 6819 s wall on the harness.
Measured after the fix (T8-prove-detection-after.json):
    control_passed = True, detected = 17/17, ok = True, 112.9 s
Single-mutation D01: 51.4 s -> 16.5 s.

The fix pruned generated/vendored directories (output, out, vendor, .agents,
.hypothesis, sample-gad-drawings, learn-media, .deps, .verify, temp) and binary
extensions from the copy. "ATTACHED ASSETS" was deliberately NOT excluded: its
markdown files are linked from README.md, so excluding it made the control run
fail on a false dead link.

The test's own `timeout=900` budget was left unchanged: the defect was copy
volume, not the budget, and the harness now finishes in ~113 s.
