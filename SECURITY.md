# Security policy

Report a suspected vulnerability through GitHub's private vulnerability reporting
feature when it is available. Request a private maintainer contact if the feature
is disabled. [BridgeCAD security reporting](https://github.com/CRAJKUMARSINGH/BridgeCAD-Enterprise-Suite/security)

Include the affected commit or release, the product entry point, the impact, and
reproduction steps using synthetic data. Remove credentials, customer workbooks,
and identifying project information from anything you send. Coordinate public
disclosure with the maintainers.

Direct corrections to drawing calculations, clause references, and assumptions
through the engineering review process in [CONTRIBUTING.md](CONTRIBUTING.md).
