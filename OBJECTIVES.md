# OBJECTIVES — maintenance scripts

Standard objective book for the repository's cleanup and housekeeping scripts.
Each entry states **what the script cleans**, **what it never touches**, and
**how a user selects or skips categories**.

## Standing rule — clean never stops running tools

Cleanup removes **files and directories only**. It never kills processes, so
running browsers (Playwright/Chromium under `.playwright-browsers/`), AI tools,
editors, dev servers and `git` itself are never interrupted. `git-locks` even
defers to `clear_stale_locks.py`, which skips when a git process is alive.
Protected names (`.git`, `.github`, `.agents`, `.env*`, `ATTACHED ASSETS`,
`CODE-JUNCTION`, `.playwright-browsers`) are refused everywhere.

Outside-the-repo cleaning is whitelist-only: `os-temp` touches aged files in
the system temp dir, and `ide-caches` touches only known cache subdirectories
inside each AI IDE's `%APPDATA%` folder. IDE settings, sign-ins, Local
Storage, IndexedDB, Preferences and User profiles are never deleted, and
locked files are skipped so running tools are not disturbed.

## `scripts/clean.py` — selectable workspace cleaner

| Category id | What it cleans |
|---|---|
| `dist` | `build/`, `dist/`, `*.egg-info/` — regenerated by `make build` / `pip install` |
| `pycache` | every `__pycache__/` outside dependency trees |
| `pytest` | `.pytest_cache/` |
| `mypy` | `.mypy_cache/` |
| `ruff` | `.ruff_cache/` |
| `hypothesis` | `.hypothesis/` example database |
| `coverage` | `.coverage`, `coverage.xml`, `htmlcov/` |
| `robot-artifacts` | `artifacts/robot/`, `artifacts/browser_check/`, `.screenshots/` (tracked `artifacts/TRIAGE_LOG.md` kept) |
| `draw-baselines` | `tests/draw/baselines/*.hash` — forces PNG baseline re-verification |
| `node-modules` | `node_modules/` trees — reinstalled by `npm ci` |
| `os-temp` | files in the system temp dir (`%TEMP%`) older than 7 days — temp dirs and in-use files are never touched |
| `ide-caches` | cache subdirs only (`Cache`, `Code Cache`, `CachedData`, `CachedExtensionVSIXs`, `GPUCache`, `DawnGraphiteCache`, `DawnWebGPUCache`, `Crashpad`, `logs`, `blob_storage`, `Service Worker/CacheStorage`, `Service Worker/ScriptCache`) inside `%APPDATA%` for **Antigravity IDE, Cursor, Kiro, Qoder, Replit, Trae, devin, Windsurf** — settings, sign-ins, Local Storage, IndexedDB and profiles are never touched; close the IDEs for a complete clean |
| `git-locks` | stale `*.lock` files in `.git/` via `clear_stale_locks.py` |

**User selection (untick):**

- Interactive: `python scripts/clean.py` or `make clean-select` — every category
  is shown checked; enter numbers to exclude, Enter to clean all.
- Non-interactive: `make clean SKIP=pytest,mypy`, `make clean ONLY=dist,pycache`,
  or `python scripts/clean.py --only dist --skip mypy`.
- `--list` shows categories, `--dry-run` previews, `--yes` cleans everything.

**Statistics:** every real run records pre- and post-clean free space, bytes
freed (total and per category), paths removed, duration and categories to
`~/.bridgecad/clean_stats.json` on the local machine — so statistics work on
any PC without touching the repo. On every **50th run** a full pre/post report
prints automatically, including a per-category breakdown that marks the
AI-tools/machine categories (`os-temp`, `ide-caches`); `--stats` prints it on
demand, `--no-stats` opts out.

## Other cleaning-related scripts and targets

| Script / target | What it cleans or resets | Notes |
|---|---|---|
| `make clean` | all `clean.py` categories | thin wrapper: `clean.py --yes` |
| `make clean-select` | user-selected categories | interactive untick picker |
| `make wing-rebaseline` | `tests/draw/baselines/*.hash`, then regenerates PNG baselines | verification step, not just deletion |
| `scripts/clear_stale_locks.py` | stale `index.lock`, `HEAD.lock`, `AUTO_MERGE.lock`, `packed-refs.lock`, `ORIG_HEAD.lock`, `next-index-*.lock` in `.git/` | `--dry-run` previews; refuses while git runs unless `--force` |
| `scripts/fix_e2e_fixtures.py` | removes stale E2E fixture files | fixture repair, not general clean |
| `scripts/generate_random_drawings.py` | `--out` dir before regeneration | scoped to its own output dir |
| `scripts/generate_all_pwd_gads.py` | temp `stage_root` / `final` dirs | scoped to its own staging dirs |

None of these stop browsers, AI tools or any other running process.
