📖 How to Use — Step by Step

1

Download a Template or Sample

Go to Downloads and grab an Excel template matching your bridge type. Templates have all required parameters pre-filled to IRC standards. Alternatively, pick a Maharashtra PWD standard type in the PWD Generator tab — no Excel needed.

2

Edit the Excel File (if using workbook input)

Open the .xlsx in Excel or LibreOffice Calc. Edit only the Value column. Key parameters:

  • NSPAN — Number of spans
  • SPAN1 — Span length (m)
  • CCBR — Carriageway width (m)
  • DATUM / TOPRL — Datum and road formation levels (m RL)
  • SKEW — Skew angle in degrees (0 = straight)

Full parameter reference: see §Parameters below.

3

Open the App and Choose Your Path

Open App ↗ in a new tab. You have three entry points:

  • 📐 Drawing Gen tab — upload your Excel file, pick scale & format, generate 9-sheet DXF/ZIP.
  • 🎛️ PWD Generator tab — no Excel needed. Select a PWD bridge type, adjust sliders, generate directly.
  • 📁 Load Project tab — parse a workbook and explore metadata before generating.
4

Choose Format and Scale

In the Drawing Gen or PWD Generator tab, select:

  • Format: DXF only • DXF + PNG preview • Full ZIP (DXF + PDF + BOQ + QA)
  • Scale: Auto (largest IRC SP:55 rung that fits) • 1:50 • 1:100 • 1:200 • 1:500

For 270 m bridges (9 spans) the auto-scale selects 1:500 and splits Sheet 2 into two bands with match-lines.

5

Run QA Check (Recommended)

Go to ✅ Validate tab. The IRC compliance engine scores your bridge 0–100 and flags issues like insufficient freeboard, weak SBC for open foundation, or span/depth ratio below IRC 112 minimum. Download the HTML report.

6

Download DXF Package

Click ⬇ Download DXF Package (ZIP). The ZIP contains all 9 DXF sheets plus a params.resolved.json with the exact parameter set that produced the drawings — a provenance record.

7

Open in CAD / Viewer

Open the DXF files in AutoCAD, BricsCAD, LibreCAD, or the free Autodesk A360 viewer (drag & drop). To convert to PDF: ezdxf draw -o out.pdf file.dxf.

🎛️ Vary Variables — Parametric Control

🔒

Variable Classes

FREE — Engineer dials. Full IRC-bounded range.
LOCKED — Booklet identity. Fixed per standard type.
DERIVED — Auto-calculated. Never type by hand.

⚙️

Auto-Derived Fields

When you change any FREE variable, the engine instantly recalculates:
total_length = Σ span_lengths • soffit_level = RTL − deck − WC − girder • pier_count = spans − 1 • bearing_type from superstructure + span

💻 CLI sweep examples

# Vary pier height 6–12 m in 3 m steps for type 001
python scripts/generate_all_pwd_gads.py \
  --type BR-I-2022-001 --sweep pier_height_m=6:12:3

# Change span length and carriageway together
python scripts/generate_all_pwd_gads.py \
  --type BR-I-2022-007 --set span_length_m=18 --set carriageway_width=11.0

# Dry run — resolve and print without generating DXF
python scripts/generate_all_pwd_gads.py \
  --type BR-I-2022-010 --sweep pier_height_m=10:16:2 --dry-run

🎛️ Format & Layout Choice

📷

DXF (default)

Full 9-sheet package. Open in AutoCAD, BricsCAD, LibreCAD, or the A360 viewer (drag & drop).

🖼️

PNG Preview

150–200 dpi raster of each sheet. Check geometry without a CAD viewer. Generated inline in the app.

📄

PDF via ZIP

Full bundle — DXF + PDF + BOQ Excel/CSV + QA HTML + manifest.json. Generated by Export Bundle tab.

Scale selection — how the engine picks the right rung

The engine picks the largest IRC SP:55 standard rung (1:50 → 1:500) where text ≥ 2.5 mm and annotation gaps ≥ 8 mm per pier label. For the 270 m 9-span type 010 this produces 1:500 with two horizontal bands and match-lines.

Override on the CLI: bridgecad draw booklet bridge.xlsx -o out/ --scale 200

💻 API & CLI — Developer Reference

REST API

# Generate DXF via REST API
curl -X POST /api/predict \
  -F "excel_file=@bridge.xlsx" \
  -G -d "format=dxf" \
  --output bridge.dxf

# Full ZIP bundle
curl -X POST /api/package \
  -F "excel_file=@bridge.xlsx" \
  --output bridge_bundle.zip

CLI Commands

# 9-sheet DXF package
bridgecad draw booklet bridge.xlsx -o out/

# Generate all 15 PWD types
python scripts/generate_all_pwd_gads.py

# Validate against IRC rules
bridgecad validate bridge.xlsx

# Price the BOQ
bridgecad bill gen bridge.xlsx -o out/
