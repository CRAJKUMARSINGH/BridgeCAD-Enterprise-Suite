# Code of conduct

BridgeCAD adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to project spaces and when acting as a project representative.

Report conduct concerns privately to the repository maintainers. Include the
relevant context and tell the maintainer how to contact you securely. Maintainers
review reports confidentially and apply the covenant's enforcement guidelines.
